# Isleward1.0 TEST
Native Java/Canvas Android8+ Shimaguni-style room island puzzle. Shade one edge-connected dark island in each outlined room. A/B/C/D totals give each island size. Dark tiles cannot share an edge across room borders. Neighbor rooms have different island sizes. Twelve unique 4x4 region/count boards, undo/reset, saved island palette and room labels, GG007 menu/site/privacy.

Independent Java coordinate-adjacency and set-BFS oracle checks all 65536 masks per board against production region counts and bitset floodfill. Every board has one solution and connected rooms. Bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, levels, taps, win, next and persistence pass. Actual drawing pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Not final or Play published.

Registry803 plus ALL local-game functional scan found no Shimaguni/room-island puzzle. Unlike Blockbloom rectangular dark groups and region shade totals, these dark islands may have any connected shape but cannot touch across room borders, and adjacent rooms must have different island sizes. Unlike Reefhaven, each island is confined to a predefined room; there is no white sea-connectivity rule. Known genre variant, not global invention. Twelve unique room/count boards on one 4x4 grid.
